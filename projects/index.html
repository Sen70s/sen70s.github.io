这里整理了我主导或参与的核心开源项目、个人工具与实验性作品。

01. 轻量化端侧多模态交互助手 (Project Alpha)

  • 一句话简介：基于端侧轻量化模型的智能多模态交互桌面客户端，实现低延迟本地化推理与平滑 UI 体验。
  • 技术栈：Python ONNX Runtime Tauri Vue 3 TypeScript
  • 核心实现与踩坑亮点：
    • 端侧量化与内存优化：采用 INT8 权重量化将显存与内存开销降低 60%，在主流消费级设备上实现毫秒级首字输出。
    • 跨平台低开销架构：基于 Rust + Webview 实现轻量化常驻托盘与悬浮交互层，整包体积压缩在 15MB 以内。
    • 踩坑与攻坚：排查并解决了端侧流式推理引发的 UI 主线程微卡顿，设计了基于独立 Worker 线程池与环形缓冲区的解耦调度方案。
  • 项目链接：GitHub - Sen70s/project-alpha

02. 极简个人知识管理与自动化发布系统 (Project Beta)

  • 一句话简介：基于 Hexo 与 CI/CD 的现代化静态博客工作流，打造沉浸式内容聚合与极速发布管道。
  • 技术栈：Node.js Hexo GitHub Actions Shell Markdown
  • 核心实现与踩坑亮点：
    • 全自动化 CI/CD 流水线：配置 GitHub Actions 工作流，代码 Push 即触发自动化依赖检查、多分辨率资产压缩与多节点部署。
    • 响应式美学定制：基于 Frame 主题拓展极简画框设计语言，对中文字体层级与暗黑模式（Classic/Dark）进行细腻适配。
    • 踩坑与攻坚：修复了分类生成器动态路由与独立静态页面同名时的冲突隐患，建立了 Front-matter 统一规范。
  • 项目链接：GitHub - Sen70s/project-beta

03. 算法生成艺术与着色器实验场 (Project Gamma)

  • 一句话简介：探索 GPU 着色器数学之美与程序化图形生成的交互式 Web 实验场。
  • 技术栈：WebGL Three.js GLSL Canvas API
  • 核心实现与踩坑亮点：
    • 着色器物理模拟：纯 GLSL 实现 Perlin 噪声流体与光线投射模拟，充分利用 GPU 并行流水线达成 60 FPS 稳定帧率。
    • 即时交互渲染控制：集成参数微调面板，支持参数实时热重载与高质量 4K 矢量画面导出。
    • 踩坑与攻坚：排查并解决了移动端 WebGL 页面切换时的上下文丢失（Context Lost）与高 DPI 屏幕下的视口畸变问题。
  • 项目链接：GitHub - Sen70s/project-gamma
